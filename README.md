# AutoTagAdmin

Приложение администратора системы доступа AutoTag.

## Установка на новый телефон

**[Скачать последнюю версию AutoTagAdmin.apk](https://github.com/artm070870/AutoTagAdmin-Update/releases/download/latest/AutoTagAdmin.apk)**

Ссылка постоянная: при выпуске новой версии файл `AutoTagAdmin.apk` автоматически заменяется свежей сборкой.

После скачивания Android может запросить разрешение на установку приложения из этого источника.

## Обновление

После первоначальной установки дальнейшие обновления можно выполнять непосредственно в AutoTagAdmin:

**Приложение → Проверить обновление**

Приложение проверяет актуальную версию и при наличии новой предлагает её установить.

---

Исходный код AutoTagAdmin хранится отдельно в закрытом репозитории. Этот публичный репозиторий используется только как канал установки и обновлений.
